## 🚀 How to Use

<div align="center">

### ⏱️ Takes only 3 minutes!

</div>

| Step | Action |
|:----:|--------|
| **1** | Click **Fork** button (top right) |
| **2** | Click **Code** → **Codespaces** → **Create codespace on main** |
| **3** | Wait 2 minutes for setup |
| **4** | Go to **PORTS** tab → Port **443** → **Public** |
| **5** | Copy the `vless://` link from terminal |
| **6** | Open VPN app → Import from clipboard → Connect |

## ❓ Troubleshooting

<div align="center">

| Problem | Solution |
|---------|----------|
| 🔴 Can't connect | Make sure port 443 is **Public** |
| ❓ Link not showing | Run `show-link.sh` |
| ⏰ Codespace stops | Run `tmux attach -t ternux` |
| 🐌 Slow speed | Try a different IP address |
