## 🚀 How to Use

### Step 1: Fork the Repository
- Go to GitHub and **Fork** this repository

### Step 2: Run on Codespaces
1. Click the **Code** button
2. Select the **Codespaces** tab
3. Click **Create codespace on main**

### Step 3: Get Your Proxy Link
- The VLESS link will appear in the terminal automatically

### Step 4: Set Port to Public
- Open the **PORTS** tab
- Find port **443** and set **Visibility** to **Public**
